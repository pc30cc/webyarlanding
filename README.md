# WebYar فارسی ساز

میخام یک پروژه جدید بسازم با نام WEBYAR و دقیقا از Project Duplication Hub کپی بشه ولی کاملا تک زبانه و فارسی باشه و بقیه زبانهاش حذف بشه کاملا و زبان فارسی و قالب فارسیش نگه داشته بشه . میخام دیتابیس جوری طراحی بشه که راحت به psql هم بشه انتقال داد برای یوزرش اصلا نمیخام از auth سوپابیس استفاده بشه . میخام تمام چیزها داخل جداول دیتابیس باشه که براحتی بتونم بک اپ بگیرم و منتقل کنم و یا حتی به phpmyadmin منتقل کنم . الان تو دیتابیسی که اضافه کردم اگه چیزی هست کلا پاک کن و دوباره بساز . دقت کن فایل های پروژه کامل هست فقط چیزهایی باید ویرایش یا حذف کنی .
